# Tree Mapper (Ver.1) 取扱説明書および仕様書

このドキュメントは、樹木マッピングアプリ「Tree Mapper」の基本的な使い方、他の人と共有する際の方法、および運用上の注意点について記述した仕様書です。

---

## 🌻 1. アプリの概要

「Tree Mapper」は、スマートフォンやタブレットのブラウザ上で動作する「ツリーマッピング（樹木の配置や情報の記録）」専用のウェブアプリケーションです。
独自に用意した地図画像（平面図や航空写真など）をアップロードし、その上に自由にピンを打って「何の種類か」「どんな情報があるか」「写真」を記録し、グループごとに管理することができます。

### **主な機能（Ver.1.0.0）**
*   **地図画像の取り込み・切り替え**: 任意の画像（JPEG/PNG等）を複数枚アップロードし、ドロップダウンから自由に切り替え可能。
*   **直感的なマップ操作**: 指2本を使ったピンチイン・ピンチアウト（拡大・縮小）、スワイプによるパン（移動）に完全対応。
*   **情報・写真付きピンの作成**: 樹木の種類ごとに自動色分けされるピンや、スマホカメラで撮影した大容量写真を自動圧縮して添付する機能。
*   **グループによる表示フィルター**: 「Aエリア」「第1工区」など独自のグループでピンを管理し、フィルターアイコンから一括で表示・非表示が可能。
*   **ローカルファースト（完全オフライン対応型バックエンド）**: ブラウザ内蔵の大容量データベース（IndexedDB）を使用しているため、外部サーバーへの通信なしでサクサク動作し、通信圏外（オフライン）でも利用可能。

## 📖 2. 使用方法

### **① アプリの起動とマップの登録**
1. アプリを起動すると「新しいマップ」の画面が表示されます（初回のみ）。
2. 「画像をアップロード」ボタンを押し、ベースとなる平面図や風景の画像を選択します。
3. マップの名前（例：北側広場）を入力すると、登録されてマップ画面が開きます。

### **② ピンの登録と写真の添付**
1. マップ上でピンを置きたい場所をタップ（またはクリック）します。
2. 開いた画面で、以下を設定します。
   * **写真**: エリアをタップしてスマホカメラで直接撮影するか、画像ファイルを選びます（自動的に軽量化されます。画像削除も可能）。
   * **グループ**: 「デフォルト」または「+ 新しいグループを作成...」から自由に入力できます。
   * **樹木の種類**: 「シラカシ」「ケヤキ」、または「+ 新しい種類を追加...」から名前を入力し、ピンの色を選びます（すでにある色は選べません）。
   * **メモ・ラベル**: その樹木の状態や特記事項を入力します。
3. 「保存する」を押すと、指定した場所にピンが立ちます（写真付きの場合はピンの右上に赤ポチが付きます）。

### **③ マップの切り替えと削除**
*   画面左上のドロップダウン（▼）をタップすると、別のマップに切り替えたり、「+ 新しいマップを追加」から２枚目以降の地図を追加できます。
*   画面右上の「ゴミ箱アイコン（リセット）」を押すと、現在開いているマップ画像と、そこに打たれたすべてのピンが削除されます（復元不可）。

### **④ ピンの一括非表示（フィルター）**
*   画面右上の「漏斗（フィルター）アイコン」をタップすると、グループのリストが開きます。
*   チェックボックスを外すことで、特定のエリアやグループの樹木だけを一時的に隠すことができ、画面が見やすくなります。

## 🤝 3. 他の人と共有する方法（デプロイメント）

現在、このアプリは **開発者のPCで直接動かして、家庭内LAN（Wi-Fi）経由でスマホから見ている状態** です。
もし「離れた場所にいる知人」や「外部の仕事仲間」にアプリを使ってもらう場合、以下の手続きが必要です。

### **ステップ1: アプリ本体をインターネット上に公開する（ホスティング）**
「Vercel(バーセル)」「Netlify(ネットリファイ)」「GitHub Pages」といった無料のWebホスティングサービスを使用し、今回の「Ver.1のコードファイル」一式をインターネット上にアップロード（デプロイ）します。（※具体的なデプロイ方法は、Viteの公式手順などに従うだけで数分で完了します）。
これにより、`https://my-tree-mapper.vercel.app` のような専用URLが発行されます。

### **ステップ2: URLを共有して使ってもらう**
発行されたURLをLINEやメールで仲間に送信すれば、仲間も同じアプリを開けるようになります。

### **⚠️ 【重要】共有時のデータ管理仕様に関する注意点**
このアプリは「ローカルブラウザDB（通信不要型）」を採用しているため、**あなたが入力した「ピン」や「写真データ」は、サーバーではなく「あなたのスマホ本体」だけに保存**されています。

そのため、URLを他人に共有して開いてもらったとしても、**「あなたの打ったピン」や「アップした地図」が最初から表示されるわけではなく、相手側は「まっさらな初期画面」からスタート**し、それぞれが独自の環境として使うことになります。

> **打開策**
> もし「自分が打ったピン一覧」も他人に見せたい、共有したい場合は、現状のVer.1では実現できません。今後のアップデート（Ver.2等）にて「データのエクスポート・インポート機能（データをファイルとして吐き出してLINEで送受信できる機能）」や「クラウドデータベース連携機能（Google DriveやFirebase等を使い、全員が同じデータをリアルタイムに見れる機能）」を追加開発する必要があります。

## 🚨 4. データ管理や運用上の重要視点 (注意点)

1. **シークレットモードでの利用について**
   スマートフォンのブラウザ（SafariやChrome）の「プライベートモード」や「シークレットモード」で開いた場合、アプリを閉じると同時に「すべてのピンと写真データが消滅」します。必ず通常のブラウザモードで利用してください。

2. **ブラウザのデータクリアによる消失**
   「キャッシュの消去」や「Webサイトデータを削除する」といった操作をスマホの設定画面で行うと、このアプリのデータベース（IndexedDB）の保存内容も巻き添えになって初期化されてしまいます。大切なデータを入れる際はご留意ください。

3. **容量制限の突破と動作**
   LocalStorageからIndexedDBへ移行済みなため、数MB単位の写真やマップを登録してもエラーで止まることはありません。ただし、スマートフォン本体のストレージの空き容量が少なすぎる場合は保存できなくなる可能性があります。
